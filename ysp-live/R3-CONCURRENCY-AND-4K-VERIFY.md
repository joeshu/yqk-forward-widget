# YSP Live R3 验证报告

该 R3 包基于用户提供的 ysp-live-v9.5.zip 整理，作为独立测试候选存档；仓库当前 v9.5.19 主线未被替换。

## 变更

- 串行化设备控制请求的节流等待与请求过程。
- 同一设备 slot 的并发初始化共用一次会话 bootstrap。
- 快速启动流程等待遥测和预热完成后再发布会话。

## 验证

- Python：32 项测试通过。
- Node：5 项测试通过。
- 设备接口：R3 初始化流程成功；同一会话下 CCTV1 与 CCTV4K 的 live 接口本次均返回 HTTP 400，未取得媒体流，无法验证编码分辨率。
- CCTV4K 的 `uhd` 备用流此前实测为 1920×1080，不能认定为真 4K。

完整源码、测试和报告见同目录的 `ysp-live-v9.5-optimized-r3.zip`。
