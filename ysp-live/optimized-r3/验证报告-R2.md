# R2 实际验证结果

日期：2026-10-18。环境：Python 3.12.14、Node.js 24.19.0。

本轮以正常启动的 R2 程序继承环境 HTTP/HTTPS 代理完成验证，没有使用上一轮的网络适配器，也没有替换网络函数。视频分片经 R2 的签名网关地址下载后，再使用 FFprobe 检查。

Web 引擎在间隔 4 秒后刷新仍返回 200，播放列表推进；本次刷新耗时约 0.17 秒。这是单次样本，不代表所有环境的耗时。

高码率设备接口仍返回 HTTP 400，R2 正确记录首次 15 秒冷却并回退。CCTV-4K 频道名称不等于实际 4K 分辨率，本次不能宣称真 4K 已修复。

回归检查：30 项 Python 测试、5 项 Node 测试通过。代理相关测试使用本机测试代理与临时证书，覆盖 HTTP 转发、HTTPS CONNECT、证书检查、认证隔离及内网拦截；Web 引擎测试验证并发合并和播放列表刷新时不重复鉴权。

前一轮原样运行的 CCTV-1 / CCTV-11 503 源于程序不使用环境代理；R2 已在同一云环境直接取得真实媒体。湖南卫视本轮抽测成功，但不能由单次成功推断多小时稳定性。

没有全频道轮巡、GUI 播放器测试或持续负载压测。
