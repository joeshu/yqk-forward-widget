# CCTV-2 单文件 Python 订阅实测

日期：2026-10-19 UTC。

## 可直接使用的项目文件

本仓库已经包含基于原作者 ysp-live v9.5 的单文件派生版，不必再复制出一套重复服务：

<https://raw.githubusercontent.com/joeshu/yqk-forward-widget/refs/heads/main/ysp-live/ysp-live-v9.5.19.py>

需要 Python 3.10+。下载后运行：

```sh
python ysp-live-v9.5.19.py 18767 --bind 127.0.0.1 --no-4k --no-engine
```

播放器订阅：

```text
http://127.0.0.1:18767/all.m3u
```

单台播放：`http://127.0.0.1:18767/cctv2.m3u8`。其他设备访问时，将监听地址改为 `--bind 0.0.0.0`，订阅使用运行 Python 的设备局域网 IP。端口可用位置参数修改。原有 PHP 服务可继续使用自己的端口；两个服务不能同时绑定同一 IP 的同一端口。

这个命令使用现有 Python 备用取源路径，不启用设备高码率与 Node 伴生引擎。Python 文件自身包含支持模块，不需要下载同目录其他 Python 文件，不需要 pip 依赖。完整配置和可选节目单见 [README](README.md)。

## 本轮真实检查

把仓库内 `ysp-live-v9.5.19.py` 单独复制到空运行目录，以端口 18769、`--no-4k --no-engine --no-epg` 启动，数据写入独立临时目录。关闭 EPG 是为隔离本次视频验证，不是视频播放的必需设置。没有添加个人账号、修改节目权限或移植央视网页的解密组件。

| 检查 | 结果 |
| --- | --- |
| `/all.m3u` | HTTP 200，64 条配置条目，约 0.01 秒 |
| `/cctv2.m3u8` | HTTP 200，14 个 EXTINF，首次响应约 2.04 秒 |
| 经本地服务获取首个视频分片 | HTTP 200，2,202,232 字节，约 2.93 秒 |
| ffprobe | H.264，1920×1080；AAC 音频 |
| FFmpeg `-xerror` 解码 25 帧 | 退出码 0，无错误输出 |

本次仅验证 CCTV-2 短样本；64 是配置条目数，不能当作全部频道已验证成功。没有验证用户手机环境、全部频道、EPG 本轮更新、4K、Node 增强或长期播放稳定性。列表耗时不等于播放器首帧耗时，上游地址和节目权限可能变化。

## 与央视手机网页测试的关系

该服务使用央视频取源路径，不是对 `tv.cctv.com` 网页加密分片的普通透传。此前央视手机页能在完整官方播放器中正常播放，而下载的加密分片不能直接解码；这与本次央视频来源分片解码成功并不矛盾。

用户提供的参考地址 `https://garysclub.sharewithyou.dpdns.org/ysp-live/ysp-live-v9.5.py` 在本次环境返回 HTTP 403，未能重新读取。因此本轮依据仓库现有派生版及其作者声明进行检查，未声称对远端文件完成逐行比对。保留 [原作者社区](https://t.me/garysclub) 和 [频道](https://t.me/garysclubchannel) 归属。
