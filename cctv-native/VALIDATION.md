## 解释范围

离线测试通过只证明所覆盖的路由、边界和重组行为。成功获取清单、分片或 `media_ready=true` 不能替代视频正常解码。即使本轮实播成功，也只代表该版本在当时网络下的 CCTV-2 样本，不承诺所有网络、设备或其他频道可用。

未绕过上游 `play != 1` 拒绝。当前只接受已支持的 TS / H.264 结构；分片末尾完整性通过相邻 HLS 序号、下一片起始码证明，媒体增长、未知格式或跨不连续边界时失败，不静默返回可能损坏的内容。

## 已修复的持续播放故障

早期短时播放成功，延长检查后出现参数缓冲区污染及 WASM 越界。在捕获的失败样本中，原有 2KiB 媒体余量不足以保护相邻参数区。现为每个媒体单元增加至少 64KiB、且不小于输入长度的有界余量，输入的逻辑长度保持原值；按官方调用方的生命周期，为玩家操作保留 2KiB 工作区，并为每次操作和每次分发独立分配、释放名称参数。官方组件本身没有修改。

合成 ABI 回归在不联网的情况下模拟参数修改及工作区需求，并覆盖多帧、多批次和大响应写完后再退出。22 个真实 TS 样本（含此前必现失败片段）由同一个运行时处理，再逐片严格音视频解码，全部退出 0，错误日志为空。另有上表三分钟本地 HTTP 实播验证，按实际进度核对，避免将提前 EOF 的退出 0 误判为完成。
