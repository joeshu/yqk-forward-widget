# 0.17.8：导航与有界资源加载

## 本轮改动

- 底部调整为 CCTV｜频道｜影视｜资源｜设置；收藏放入频道菜单。
- 资源页集中订阅导入、订阅列表和脚本服务入口。影视页暂为明确的空状态；通用影视浏览仍未接通。
- 台标加载从无界任务数组改为共享加载器：同 URL 合并、4 路并发、96 个待处理来源上限、单响应 2 MB 上限、192 像素后台缩图、16 MB/200 项解码缓存、30 秒失败退避。播放优先窗口取消图片任务，内存警告清理缓存。
- 图片结果同时检查加载代次和视图绑定地址，避免已复用单元格显示旧台标。完成任务及时从索引中移除。
- 备用源重试记录本次已尝试地址，最多 4 个不同地址；跳过禁用订阅，保留原频道元数据。手动重新选台重置重试预算。旧播放器的迟到失败回调不能切换当前频道。
- 服务列表缓存分组，内容及运行状态未变化时不重绘；详情页轮询只在运行状态变化时刷新状态分区。
- 资源频道计数由每个资源扫描所有频道，改为单次遍历累加；每项资源只读取一次元数据。
- JS 适配器初始化失败尝试关闭原生会话，保留最初错误。成功返回 HLS 后，后台 EPG 调度失败不会再向同一连接写入第二个 502 响应。

## 验证范围

Python HTTP 回归增加初始化清理和可选 EPG 失败场景。模拟器检查增加五个导航页、备用源预算/禁用订阅、图片去重/后台缩图/过大响应/视图复用场景。模拟器使用本地真实 HTTP、AVPlayer 和图片解码，原生 CCTV SDK 由测试替身代替。

必须以实际测试结果更新交付说明。模拟器和静态检查不能证明私有 SDK 真机首帧时间；本轮不宣称开台速度提升某个百分比，也不改变 SDK 的认证或私有缓冲接口。
