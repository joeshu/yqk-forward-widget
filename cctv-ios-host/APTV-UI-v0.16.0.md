# CCTVHost 0.16.0 界面与功能

以用户提供的 APTV 截图为布局参照，使用 CCTVHost 自身名称、系统图标和已有频道数据。
不包含 iCloud。

## 已接入的功能

- 黑色背景、深色圆角卡片、粉色强调色、大标题和底部直播 / 收藏 / 配置 / 设置导航。
- 首页默认双列频道网格，宽屏自适应；右上角切换单列列表并保存偏好。
- 分组、搜索、下拉刷新、频道长按菜单、收藏、最近观看；选台后展开播放器。
- 播放器下方可切换频道、节目单和信息；保留暂停、静音、线路选择、全屏、手势及 AVPlayer 画中画。
- 配置中心展示真实频道数量；订阅与官方目录可启停、搜索、选择、刷新或删除。
- 服务列表按运行状态分组；详情包含端口、地址复制、GET / 检测、日志、代码查看/导出、编辑、删除和添加 M3U 订阅。
- Python 服务可从文件、HTTP/HTTPS 链接、手动代码导入；支持编辑代码、名称、端口和启动参数。
- 内置 YSP 服务可选择绑定本机或局域网；自定义脚本的网络绑定由脚本参数决定。
- 节目单按接口返回的实际日期切换，使用北京时间，突出当前节目；读取订阅 tvg-id 匹配官方频道。
- 播放信息按真实可用数据展示引擎、首帧、线路偏好；订阅源可展示分辨率和观测带宽。
- 本机订阅、收藏和偏好可用 JSON 导入/导出；文件先校验，导入前在界面确认替换。

## 明确边界

- 现有 CPython 宿主每个 App 进程只安全启动一次、同一时间一个 Python 服务。
  停止后需重新打开 App 再启动。没有伪装成可多服务并行或无限重启。
- 自定义 Python 脚本使用内置标准库；第三方包和 Android / Node.js / 原生插件不保证兼容。
  启动参数以 `|` 分隔，支持 `{port}`、`{bind}`、`{dataDir}`。
  自定义服务需要停止能力时，可向 `builtins._cctvhost_stop_service` 注册返回真值的可调用对象。
  无停止回调时，界面报告失败，保持真实运行状态。
- 自动刷新远程服务代码、后台常驻、任意 XMLTV 来源、历史节目回看没有实现；
  不显示无效开关。节目回放需要播放源提供真实回看地址。
- 自定义 Python 代码单独导入/导出，不混进配置 JSON。未改变官方 SDK 的鉴权机制。
- 没有 iCloud 入口、开关或同步请求。

## 验证

- 既有回归检查保留；旧“仅单列”约束改为检查网格/列表并存。
- macOS Foundation 原生测试验证备份拒绝无效输入、导入导出往返、服务持久化和删除。
- macOS 工作流编译真机 arm64 IPA，执行结构校验。
- 独立的模拟器 UI 测试使用 SDK 空实现（不会打入 IPA），检查网格、收藏、配置导航、服务详情、
  服务编辑保存及列表切换，并生成页面截图。EPG 截图明确使用测试数据。
- 模拟器 UI 检查不代表官方 SDK、DRM、真机切台或任意远程脚本已通过实测。
