# Channel logo assets

The bundled `ChannelLogo_<channel-id>` image sets provide an offline logo for each entry in `Resources/channels.json`. A channel's own `tvg-logo` or `logo` URL still takes precedence when present; imported channels without a logo receive an ID-specific text badge.

The source PNGs are pinned to these public logo collections:

- [vircloud/TVLogo](https://github.com/vircloud/TVLogo/tree/bcb7075771a1dc8ef217f77383edb40e2bf2e762)
- [maowei1125/iptv-logo](https://github.com/maowei1125/iptv-logo/tree/76944ee79e82b1b6c5edc9bd9d1964297b67d344)

The original station marks remain identifiable as their respective broadcasters' marks.
