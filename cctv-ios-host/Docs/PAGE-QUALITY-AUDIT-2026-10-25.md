# CCTVHost 页面、菜单与体验审计

日期：2026-10-25  
范围：`cctv-ios-host/` 当前 Objective-C/UIKit 实现；最低系统版本 iOS 15。检查页面入口、菜单、状态呈现、主题、列表开销和异步生命周期。此文记录代码审计与 CI 可验证行为，不把模拟器结果等同于真机播放或性能数据。

## 已确认并在本轮修复的问题

| 级别 | 页面/位置 | 问题及证据 | 修复 |
|---|---|---|---|
| 高 | 全局日志持久化 | Root 启动后固定创建 1 秒重复 `NSTimer`，即使缓冲区为空也持续唤醒主 RunLoop；若写盘期间新增记录，旧逻辑还需要下一轮定时器再发现。 | 改为有新日志才排一个 350ms 有界批量写入；写盘完成时检查并重新安排积压；进入后台主动刷新；移除常驻定时器。 |
| 高 | 影视海报列表 | `cellForItemAtIndexPath` 每次复用都移除所有子视图，再新建图片、标题和副标题，产生可避免的 view/layout 分配并增加滚动工作。 | 新建复用海报 cell，图片、标题、副标题仅在 cell 初始化时建一次；复用时清除旧文本/图片身份。海报高度仍由已有图片加载器限幅和缓存管理。 |
| 中 | 服务列表/详情 | 服务列表为每一行创建不可复用 cell；状态通知导致全表刷新时重复分配。服务详情、资源详情和播放信息也以一次性 cell 为主。 | 服务列表、服务详情、资源详情、播放信息使用复用标识；跨状态复用时明确重置 accessory、图片和文本，避免残留控件。 |
| 中 | 资源导入 sheet | 行高固定 98pt、标题区固定 100pt，较窄屏幕或大字体下标题/说明可能截断或挤压。 | 行和分组头切换为 Auto Layout 自适应；文本使用可缩放字体并可换行，标题区根据内容测高。 |
| 中 | 设置、播放信息、频道列表 | 设置固定 58pt，播放诊断信息固定 54pt；频道表固定 48pt、海报卡片标题字体固定且不随辅助字体变化，长节目名容易挤压。 | 设置、播放信息、频道表改为自适应行高；频道卡片根据缩放字体计算高度，辅助字体变化时刷新列表布局。 |
| 中 | 全站搜索 | 搜索 header 固定 104pt，但来源进度为多行标签；狭窄宽度或动态字体下可能被裁切。 | 根据 Auto Layout fitting size 计算 header 高度，并使“历史”按钮随辅助字体缩放。 |

## 主题与性能现状

- 黑白主题通过同一套动态色板 `HostTheme.h` 应用于导航、卡片、文字、分割线和按钮；自绘 layer 边框在切换主题后显式刷新。视频画面背景维持黑色属于播放器预期，不受主题切换。
- 台标/海报图片加载使用有界请求并发、响应大小限制、缓存和失败冷却；元数据缓存也有容量/有效期边界。EPG 采用 60 秒刷新，并在页面不可见/应用后台暂停或取消可取消任务。
- 服务、插件和资源页使用运行状态通知，没有常驻 1 秒状态轮询。日志 UI 用短时间窗口合并通知。
- 这轮没有测冷启动、真实网络刷新耗时、内存峰值、真实视频首帧/切台性能；现有 GitHub CI 的播放器替身和可见视频夹具只验证宿主流程及 AVPlayer 冒烟，不替代真实来源设备播放。

## 尚未宣称解决或需要后续专项处理

1. `RootViewController.m` 仍承载频道、播放器、订阅、EPG、导入与跨页路由等大量职责；功能可用，但高耦合使后续逐页修改和定位风险偏高。应以行为测试守住状态后分批抽离协调器，避免一次性重构扩大风险。
2. Service Editor、主导航底栏、播放器叠加控制仍使用紧凑输入/控制布局；本轮动态布局修正覆盖列表和资源导入高频场景，最大辅助字体、窄屏和横屏下的编辑器排布尚需模拟器/真机逐项验收。
3. 模拟器测试不验证 CNPlayerSDK 的授权、真实 CDN/线路首帧、真实插件来源仍在线、长时间混合 Python/Node/JSC 并行运行或设备内存压力。相关结论一律标为待真机验证。

### 本轮发现并修复

日志中心之前会在页面不可见时仍接收日志通知，反复拆分完整快照、过滤并 `reloadData`；日志追加也会强制滚到列表末尾，打断用户阅读旧记录。现在日志通知只在页面前台订阅；重复快照不触发表格重载；首次打开和用户停留在列表底部时跟随最新记录，用户滚到上方后保留阅读位置；日志文字支持辅助字体缩放，复制行/筛选结果会播报操作反馈。

相关验证：`Tests.test_persistent_log` 新增日志页面生命周期、跟随底部条件、重复快照与辅助字体合同；`Tests.test_global_theme`、`Tests.test_resource_interaction_contracts`、`Tests.test_root_view_controller_contracts` 覆盖其余页面的主题、状态和异步交互。
