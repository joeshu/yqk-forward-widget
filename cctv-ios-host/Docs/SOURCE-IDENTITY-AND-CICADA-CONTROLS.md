# 窜站与 Cicada 操作修复

日志版本 1.34(507)，JSONL 共 1365 条，8 次播放交接均为 AVPlayer；未记录 Cicada 交接或显式兜底事件。不同 CDN 域名不能单独证明错片；日志未包含预期内容与最终媒体的可验证绑定。安全提取的证据见 SOURCE-IDENTITY-LOG-EVIDENCE-20261110.json。

源码已发现并修复：Python 通用适配默认猜站、跨采集站回退、数字ID调用内置短剧源；站点列表按相似名称启动其他脚本；Native bridge跨协议/跨base尝试及解析器选择失效后的默认回退。播放器遗留按片名跨站搜索实现已删除，网页提流限定播放器配置，自动分集匹配不再仅比集数或猜下标；手动换线路无法匹配时要求选集。元数据缓存升级v3，清除旧v2缓存，保留收藏与历史。

Cicada原路径隐藏AVPlayer系统控件，仅展示SDK视频视图，确实缺少可见操作栏。本轮增加播放暂停、前后10秒、时间、进度拖动、倍速/比例菜单和保留同一解码会话的全屏承载。直播无有效时长时禁用定位。

当前Linux环境不能运行UIKit行为探针或真机解码，新增操作功能须在macOS/iPhone验收。修复限制宿主自动换源；第三方源自身返回错误内容仍需要源端修复。
