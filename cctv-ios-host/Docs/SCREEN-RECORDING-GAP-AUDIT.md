# 录屏与影视聚合播放器需求差距

对照 2026-11-02 的录屏和需求稿，按当前 iOS 源码核对。录屏能确认资源列表、影视首页、资源/平台选择、详情选集和播放失败页的主路径存在；页面内容会随导入资源变化。

## 本轮已补齐

- TVBox 合集的 `parses` 配置现在按合集隔离并进入播放解析。JSON 接口可返回应用内 AVPlayer 使用的直链；网页解析会回退到应用内网页播放。选择会按影视资源保存，并跟随详情、续播和播放页换集。
- 详情海报延伸到状态栏与导航栏下面，使用整幅海报和底部渐变；原页面卡片与选集仍在可滚动内容中。
- 播放页显示 AVPlayer 报告的估算带宽；存在字幕或音轨时可在播放菜单中选择。没有弹幕轨道时明确显示不可用。
- 对损坏的本地合集记录增加类型检查，避免解析接口选择时因默认值中的非字典项崩溃。

## 仍未实现或与参考不同

| 区域 | 当前状态 | 剩余工作 |
| --- | --- | --- |
| 详情操作 | 当前是复制、分享、收藏、跳到选集 | 参考要求的搜索、离线下载、收藏、片单按钮及对应管理流程尚未齐全；媒体文件没有离线下载管理器 |
| 播放器弹幕 | 菜单会说明当前无弹幕轨道 | 没有弹幕源协议、同步与渲染实现 |
| 资源导入 | TVBox、脚本、直播列表和 ZIP 可用 | Emby/Jellyfin/fnOS、Kazumi、WebDAV/SFTP/FTP 挂载与 TMDB 刮削仍明确标为未接入，不能登录或播放 |
| 平台选择 | 从当前资源动态读取站点/平台 | 没有需求稿列出的固定平台大全；TMDB API Key 配置和 TMDB 搜索也未接入 |
| 首页分类 | 首页轮播、推荐及资源返回的分类可动态加载 | 不同资源返回的分类数和内容不同；当前不会为缺少分类的源伪造电视剧、电影、综艺、动漫、少儿、纪录片六组内容 |
| 解析接口覆盖 | TVBox JSON 解析可解析出直链；网页解析在应用内网页中工作 | 网页解析无法保证提取成 AVPlayer 直链。结果取决于解析端点、站点授权、Cookie/签名和 iOS 可解码格式；DRM 内容不会由解析接口自动变成可播放直链 |
| 原生验证 | Python 回归和交互契约可在当前环境运行 | 当前环境没有 Xcode/macOS SDK，尚未对本轮 Objective-C 修改做 iOS 编译、模拟器截图或真机播放验证 |

CCTV 与频道页保持原样，未改动其页面实现或投屏入口。
