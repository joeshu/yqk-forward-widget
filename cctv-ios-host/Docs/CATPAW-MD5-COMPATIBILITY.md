# 猫源 `.js.md5` 本机导入与播放

## 用户操作

1. 在“资源 → 添加资源 → 影视 / 猫源 / 插件链接”输入 `.js.md5`、JS 或 ZIP 地址。
2. 导入进度显示读取校验、主脚本下载、配套配置下载和识别登记；可以取消。失败会显示阶段并提供“重新下载并校验”，不会替换现有资源。
3. 导入完成后选择“启动并浏览”，或打开资源详情查看能力、校验状态和独立日志。
4. 影视顶部第一级选择已导入资源，第二级选择该资源的站点。分类、搜索、详情、线路和选集使用原生界面。
5. “更多 → 源配置与账号”打开源实际提供的本机配置页面。关闭后重新读取配置并清除此服务的浏览缓存；不会因为配置变化重建其他服务。
6. 资源详情的“检查资源更新”重新下载并核对内容。确认更新时先停止此服务，保留 ID、用户名称、端口、参数、账号目录和日志。可通过“切回上一版代码”恢复保留的代码版本。

界面来源地址保留原查询参数；运行诊断日志不记录完整来源/播放 URL、Cookie 或查询参数。

## 协议与兼容修复

- `.md5` 是主脚本校验文件，不是影视 JSON 或直播列表。支持纯 32 位校验及校验后带文件名的格式。MD5 用于一致性检查，不表示来源可信或内容一定能播放。
- 猫源候选在同目录额外查找 `index.config.js.md5` 和 `index.config.js`。校验存在时必须匹配；不存在配置时明确标记使用脚本默认值，不向 `start` 传入空对象覆盖默认参数。
- 主脚本/配套配置一起交给导入器，在同一次暂存安装中识别。脚本上限 8 MiB、ZIP 24 MiB、配套配置 64 KiB、校验文本 4 KiB；下载进度节流，重定向最多 5 次。配套配置不允许跨来源重定向。
- 支持 CommonJS 默认导出包装、ESM 配置导出；已有配置与用户覆盖项按对象层级合并，数组替换，不修改其他服务的配置。
- HTTP 猫源详情接口同时提供 `id` 和兼容旧包的 `ids`；分类、分页、搜索提供常见别名。实际源读取 `id`，旧实现只传 `ids` 会返回空详情。
- 站点按 ID 选择。失效站点报错；刷新会重新枚举源当前站点，空站点列表不伪装为单站点，也不静默选择其他站点。
- 相对海报/媒体地址按当前本机源地址解析，保留查询参数；本机播放凭据按来源范围传递。受保护海报使用独立、限量的图片代理，避免图片请求淘汰正在播放的媒体代理。
- 配置页面通过真实 HTTP/HTML 探测后才声明 `configuration` 能力。WebKit 使用该页面独立的临时存储，通过正常登录 Cookie 访问，不添加任意网页执行宿主代码的桥接。
- 新增 `POST /api/v1/invalidate`，只清除此服务的浏览缓存，唤醒旧请求等待者并丢弃失效结果。配置页返回及手动刷新调用此接口，防止旧配置/旧端口数据重新覆盖界面。
- 空详情返回 `NO_DETAIL`；详情缺少分集时显示无可播放分集并禁用播放，不补造线路。

更新使用已有服务目录中的版本子目录，原账号目录不动。切回代码不会回滚源自己写入的数据库或账号变化；若源自行进行了不兼容数据迁移，旧代码能否读取需要另行验证。保留的代码文件不会自动删除，可在明确移除资源时清理。

本轮主脚本 6,489,653 字节，MD5 `8dfd868a5875ec4ad8061e5f94ae8bf6`；配套配置 9,809 字节，MD5 `93f807174a2f253cdcf5ce9ee00f4c18`，均与远端对应校验文件一致。源后续更新时以新校验为准，不锁定这些值。

测试环境为 Linux、Node.js v24.19.0、`--jitless`，WebAssembly 不可用；外网测试保留云环境规定的代理和 CA 信任设置。此结果不是 iPhone 运行结果。

- 原始 CommonJS 源启动成功，实际枚举 96 个站点。
- `/website` 返回 HTTP 200、HTML；关闭服务成功。双服务实测中，停止猫源后其端口不可连接，另一个 Node 服务仍可浏览，随后也可独立停止。
- “短剧｜星芽”：分类 24 项，详情含分集，`play` 返回直连媒体；读取 256 KiB MP4 样本，HTTP 200，`ftyp` 有效，ffprobe 识别 H.264 720×1280 与 AAC。
- “短剧｜好看”：分类 9 项，详情含分集，`play` 返回直连媒体；读取 256 KiB MP4 样本，HTTP 200，`ftyp` 有效，ffprobe 识别 H.264 1080×1920 与 AAC。
- “漫剧｜小红”：分类 23 项；源返回的详情缺少播放分集，不能据此宣称可播放。客户端提供明确空状态。

没有验证其余站点、用户登录/网盘授权、iPhone 解码首帧和长时间播放。没有在仓库内分发第三方脚本、配套配置、账号信息或媒体样本。
